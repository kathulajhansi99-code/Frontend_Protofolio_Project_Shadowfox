# Frontend Developer Portfolio

## Files
- `index.html` — semantic website structure
- `style.css` — responsive layout and visual styling
- `script.js` — mobile menu and contact-form validation

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy
Upload the three files to GitHub Pages, Netlify, or Vercel.

## What to explain during evaluation
- Semantic HTML sections make the page structured and accessible.
- CSS Grid/Flexbox and media queries provide desktop, tablet and mobile layouts.
- JavaScript handles the mobile navigation and client-side form validation.
- The design uses consistent spacing, typography, cards and a clear visual hierarchy.
